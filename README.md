# KittyDoro 🐱✨

**KittyDoro** es una aplicación web interactiva diseñada para transformar las sesiones de estudio en una experiencia más amena, organizada y personalizada, basándose en la popular técnica Pomodoro.

---

## 🚀 Acerca del Proyecto

KittyDoro nace con un enfoque centrado en la **Interacción Humano-Computador (IHC)**, buscando reducir la fatiga mental y aumentar la motivación del estudiante mediante una interfaz acogedora y altamente personalizable. A diferencia de las herramientas tradicionales, KittyDoro permite al usuario **hacer suyo el espacio de trabajo**.

---

## ✨ Características Principales

### ⏳ Gestión del Tiempo
Implementación fluida de ciclos Pomodoro (estudio/descanso) con indicadores visuales dinámicos que cambian según el estado de la tarea.

### 🎨 Alta Personalización

#### 🐾 Personajes
Elige entre una selección de amigos entrañables:

- Hello Kitty
- Kuromi
- Pompompurin
- Y más personajes disponibles

#### 🖼️ Fondos a Medida
¿Quieres estudiar con un paisaje específico? Sube tus propias imágenes y personaliza completamente tu entorno de estudio.

### 🛠️ Herramientas Integradas

- Temporizador configurable
- Cronómetro de precisión
- Alarma personalizada
- Reloj en tiempo real

### 💾 Persistencia Inteligente
Gracias al uso de **localStorage**, tus configuraciones de personaje y fondo se guardan automáticamente. Al regresar, tu entorno te estará esperando exactamente como lo dejaste.

### ⚡ Ligero y Eficiente
Desarrollado íntegramente con tecnologías web nativas (**Vanilla HTML5, CSS3 y JavaScript**). Sin frameworks pesados, garantizando una carga instantánea y una experiencia fluida.

---

## 🛠 Tecnologías Utilizadas

### Front-end
- HTML5
- CSS3 (incluyendo animaciones dinámicas)
- JavaScript ES6+

### Funcionalidades Externas
- EmailJS para el módulo de feedback y contacto

### Persistencia
- localStorage para el almacenamiento de preferencias del usuario
